# SDD operating rules

- Read `sdd/README.md`, the workflow, `CURRENT.md`, the active request, batch, and validation checklist.
- Treat `sdd/human-requests/` as human intake and `sdd/backlog/` as a non-executable draft area.
- As Executor, write code, `sdd/implementation/`, and `sdd/validation/` only within the approved scope.
- Do not edit `sdd/SPEC.md`, numbered specifications, or `sdd/decisions/DECISION-LOG.md` without explicit human authorization.
- Preserve Chief Memory, keep Execution Memory concise, and run the smallest validation capable of falsifying the change.
