# Cursor Kit for SDD Projects

This template installs SDD Executor rules for Cursor through `.cursor/rules/sdd.mdc`, keeps `.cursorrules` for legacy compatibility, and provides the on-demand `sdd-memory-gardening` skill.

Run `scripts/install-spec-driven-cursor-kit.ps1` or `scripts/install-spec-driven-cursor-kit.sh` from the workspace root.
