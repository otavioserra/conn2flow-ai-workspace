# Kit Cursor para Projetos SDD

Este template instala regras de Executor SDD para o Cursor por meio de `.cursor/rules/sdd.mdc`, mantém `.cursorrules` para compatibilidade e fornece a skill sob demanda `sdd-memory-gardening`.

Use `scripts/install-spec-driven-cursor-kit.ps1` ou `scripts/install-spec-driven-cursor-kit.sh` a partir da raiz do workspace.
