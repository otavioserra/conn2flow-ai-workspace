# Human Requests

Esta pasta guarda o intake humano não normativo do projeto.

## Regras

- O conteúdo desta pasta não substitui `SPEC.md`, baseline, batches, decisões ou validação.
- Quando o fluxo receber apenas a pasta, resolva em ordem: `CURRENT.md`, `README.md`, depois o `.md` mais recente.
- Classifique cada intake antes de editar o código ou os artefatos operacionais.
