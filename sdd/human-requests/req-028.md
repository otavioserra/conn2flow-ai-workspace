## 🎯 1. Diagnóstico & Justificativa Técnica

Atualmente, a conformidade de agentes depende da leitura proativa de skills e do seguimento estrito de instruções em texto. No entanto, agentes sob pressão de contexto ou em sessões longas ocasionalmente cometem deslizes repetidos:
1. Tentam copiar arquivos com `cp` para sincronizar projetos locais;
2. Usam `git add .` ou `git add -A`, correndo o risco de adicionar arquivos não rastreados;
3. Deixam erros de sintaxe em PHP que só são descobertos quando o container quebra.

Ao utilizar o **Sistema de Hooks do Claude Code** (`PreToolUse` e `PostToolUse`), transformamos essas diretrizes em **travas programáticas determinísticas**: se o agente tentar rodar um comando proibido, o hook retorna `permissionDecision: "deny"` com a mensagem de correção antes do comando ser executado.

Além disso, com **`CLAUDE.md` aninhados**, as regras de cada camada da aplicação são carregadas apenas quando o agente atua naquela subpasta, economizando tokens e eliminando sobrecarga cognitiva.

## 🛠️ 2. Especificação Técnica das Alterações

### A. Criação dos Hooks em `.claude/hooks/`
1. **`.claude/hooks/pre-tool-guard.ps1`** (Windows PowerShell):
   - Lê o payload JSON via stdin;
   - Se for comando `Bash` ou `PowerShell`:
     * Bloqueia `cp`, `copy`, `Copy-Item` direcionados a `dev-environment/data/sites/` ou espelhos locais, respondendo com:
       `"Bloqueado por Governança: É proibido sincronizar por cópia manual. Utilize 'c2f manager:update-all' (sistema) ou 'c2f project:update-all <id>' (projeto)."`
     * Bloqueia `git add -A`, `git add .` ou `git add -u`, respondendo com:
       `"Bloqueado por Governança: É proibido 'git add -A'. Utilize 'git add <caminhos-especificos>'."`
2. **`.claude/hooks/pre-tool-guard.sh`** (Linux/Git Bash/macOS):
   - Script equivalente em Bash utilizando `jq`.
3. **Configuração em `.claude/settings.json`**:
   - Declarar o hook `PreToolUse` para `Bash|PowerShell`.

### B. Criação de `CLAUDE.md` Aninhados
1. **`gestor/modulos/CLAUDE.md`**:
   - Regras de desenvolvimento de módulos CRUD V2;
   - Uso obrigatório de `variables.json` para mensagens e labels (proibição de strings hardcoded);
   - Padrão de CSRF e sanitização de formulários.
2. **`resources/CLAUDE.md`**:
   - Regras dos 11 tipos de recursos;
   - Fonte da verdade em runtime (o banco serve os dados; `resources/` é semente de compilação);
   - Regra mandatória de Version Bump no JSON de recursos ao alterar scripts JS.
3. **`cli/CLAUDE.md`**:
   - Regras de desenvolvimento de comandos no Core CLI (Symfony Console);
   - Validação de skills em `AiSyncCommand.php`.

### C. Atualização dos Templates & Propagação
- Atualizar os templates do Claude Kit em `templates/pt-br/` e `templates/en/` para incluir a pasta `.claude/hooks/` e os hooks pré-configurados;
- Executar `scripts/sync-all-repos.ps1 -Force` para propagar em `conn2flow`, `lumix`, `transformamp`, `conn2flow-site`.
