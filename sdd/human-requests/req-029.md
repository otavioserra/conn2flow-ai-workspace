## 🎯 1. Diagnóstico & Justificativa Técnica

Para escalar o desenvolvimento autônomo e a coordenação entre múltiplos projetos sem atrito manual:
1. **Comunicação Direta entre Sessões**: Com o `Cross-Session Messaging` nativo, agentes trabalhando em repositórios diferentes na mesma máquina podem trocar status e avisos de breaking changes via `@sessao` diretamente;
2. **Execução até a Meta (`/goal`)**: O modo `/goal` impede que o agente pare prematurely em fatias complexas, exigindo validação determinística de critérios de aceite antes de encerrar o turno;
3. **Distribuição via Plugin**: Em vez de gerenciar cópias manuais de dezenas de arquivos de skills em múltiplos repositórios, a arquitetura de plugin permite centralizar a suíte de ferramentas do Conn2Flow em um pacote único versionado.

---

## 🛠️ 2. Especificação Técnica das Alterações

### A. Governança de Cross-Session Messaging
- Configurar em `.claude/settings.json` nos templates e masters:
  ```json
  {
    "crossSessionInbound": "allow"
  }
  ```
- Documentar na skill `c2f-system-tasks` e no Playbook o uso de `@nome-da-sessao` para sincronização entre Core e Projetos.

### B. Mapeamento do Goal Mode (`/goal`) no SDD
- Atualizar `sdd-workflow/SKILL.md` nos masters e templates para instruir o uso do comando `/goal` quando executando fatias em modo Autônomo Monitorado:
  * *"Execute o lote BATCH-XXX até que todos os testes do VALIDATION-CHECKLIST.md passem e o relatório esteja preenchido."*

### C. Estrutura do Plugin Oficial Conn2Flow (`conn2flow-devkit`)
- Criar a pasta `.claude-plugin/` na raiz do `conn2flow-ai-workspace` com o arquivo de manifesto `plugin.json`:
  ```json
  {
    "name": "conn2flow-devkit",
    "version": "2.1.0",
    "description": "Suite oficial de 36 skills, hooks e governanca para o ecossistema Conn2Flow",
    "author": {
      "name": "Conn2Flow Core Team"
    },
    "skills": "./.claude/skills"
  }
  ```

### D. Atualização dos Playbooks Multi-Agentes
- Atualizar `docs/pt-br/PLAYBOOK-ORQUESTRACAO-MULTI-AGENTES.md` e `docs/en/MULTI-AGENT-ORCHESTRATION-PLAYBOOK.md` documentando:
  * Como usar o Cross-Session Messaging entre sessões locais;
  * Como usar o comando `/goal` para execução contínua;
  * Como instalar o plugin `conn2flow-devkit`.
