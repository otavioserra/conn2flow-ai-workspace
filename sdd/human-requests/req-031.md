## 🎯 1. Diagnóstico & Justificativa Técnica

Atualmente, a escolha de topologia de agentes (Duplo vs Tríade) e dos níveis de autonomia (Supervisionado, Monitorado, Headless) dependia de declarações manuais de texto ou de conhecimento profundo do SDD.

Ao integrar um **Seletor Visual de Modos** na Extensão Oficial do VS Code (`conn2flow-tools`), o desenvolvedor ganha controle total em 1-Click:
- Alterne instantaneamente entre o modo **Duplo Agente** (ideal para tarefas ágeis ou aprendizado) e o modo **Tríade de Agentes** (com Revisor Técnico dedicado para máxima blindagem de qualidade em produção);
- Escolha o nível de autonomia com um clique, refletindo automaticamente no cabeçalho do `CURRENT.md` e da requisição ativa;
- Dispare tarefas pesadas de Docker, CSS e compilação diretamente por botões visuais com feedback imediato.

## 🛠️ 2. Especificação Técnica da Extensão

### A. Estrutura de Diretórios (`vscode-extension/`)
Criar na raiz de `conn2flow-ai-workspace`:
```
vscode-extension/
├── package.json
├── tsconfig.json
├── README.md
├── resources/
│   └── icon.png (ou conn2flow-logo.svg)
└── src/
    ├── extension.ts
    ├── providers/
    │   ├── conn2flowTreeProvider.ts
    │   └── modesManager.ts
    └── commands/
        ├── sddCommands.ts
        ├── dockerCommands.ts
        ├── managerCommands.ts
        └── projectCommands.ts
```

### B. Árvore de Navegação e Acordeões da Barra Lateral
A extensão deve registrar uma View Container com ID `conn2flow-view-container` e uma View `conn2flow-explorer` contendo os seguintes acordeões:

1. **🎛️ Modos de Operação & Autonomia**:
   - `conn2flow.modes.setDoubleAgent`: Alterna topologia para `👥 Duplo Agente` (Arquiteto + Executor).
   - `conn2flow.modes.setTriAgent`: Alterna topologia para `🏛️ Tríade de Agentes` (Arquiteto + Executor + Revisor).
   - `conn2flow.modes.setSupervised`: Alterna autonomia para `🛡️ Nível 1: Supervisionado`.
   - `conn2flow.modes.setMonitored`: Alterna autonomia para `👁️ Nível 2: Autônomo Monitorado`.
   - `conn2flow.modes.setHeadless`: Alterna autonomia para `🤖 Nível 3: Autônomo Headless`.
   *(Ao acionar qualquer um desses botões, a extensão lê e atualiza os campos correspondentes no cabeçalho do `CURRENT.md`).*

2. **🏛️ SDD & Governança Viva**:
   - `conn2flow.sdd.openCurrent`: Abre o arquivo `sdd/human-requests/CURRENT.md`.
   - `conn2flow.sdd.openSpec`: Abre o arquivo `sdd/SPEC.md`.
   - `conn2flow.sdd.openChecklist`: Abre `sdd/validation/VALIDATION-CHECKLIST.md`.

3. **🐳 Docker & Logs em Tempo Real**:
   - `conn2flow.docker.status`: Executa `docker ps` no terminal integrado.
   - `conn2flow.docker.logsApache`: Executa `docker logs conn2flow-app --tail 50 --follow`.
   - `conn2flow.docker.logsPhp`: Executa `docker exec conn2flow-app bash -c "tail -f /var/log/php_errors.log"`.
   - `conn2flow.docker.truncatePhpLog`: Executa limpeza do arquivo de log PHP.

4. **🛠️ Manager & Core (Sistema)**:
   - `conn2flow.manager.updateAll`: Dispara a tarefa de atualização completa do sistema (`c2f manager:update-all`).
   - `conn2flow.manager.syncResources`: Executa `c2f resources:sync`.
   - `conn2flow.manager.cssRebuild`: Executa `c2f css:rebuild`.
   - `conn2flow.manager.cssAudit`: Executa `c2f css:audit`.

5. **🗃️ Projetos**:
   - `conn2flow.projects.updateAll`: Dispara a tarefa de atualização de projeto selecionado (`c2f project:update-all <id>`).
   - `conn2flow.projects.deploy`: Dispara o deploy de projeto.

6. **📚 AI Workspace Hub & Documentação**:
   - `conn2flow.ai.syncSkills`: Executa `./scripts/sync-all-repos.ps1`.
   - `conn2flow.ai.validateSkills`: Executa `php cli/c2f.php ai:sync`.
   - `conn2flow.ai.openPlaybook`: Abre o `docs/pt-br/PLAYBOOK-ORQUESTRACAO-MULTI-AGENTES.md`.
   - `conn2flow.ai.openCatalog`: Abre o `docs/pt-br/CATALOGO-DE-SKILLS.md`.

### C. Marcadores de Metadados no SDD (`CURRENT.md` e `req-XXX.md`)
Padronizar o cabeçalho do `CURRENT.md` para suportar a leitura/escrita da extensão:
```markdown
# CURRENT ACTIVE REQUEST

*   **Ponteiro Ativo**: req-031.md
*   **Status**: READY-FOR-IMPLEMENTATION
*   **Topologia de Agentes**: triade (ou duplo)
*   **Nível de Autonomia**: supervisionado (ou autonomo_monitorado / autonomo_headless)
```

### D. Status Bar Items no Rodapé
1. `$(server) Docker: Online/Offline` (clicável para abrir logs).
2. `$(organization) Tríade | Supervisionado` (clicável para abrir o seletor de modos).
3. `$(git-commit) SDD: REQ-031` (clicável para abrir `CURRENT.md`).
