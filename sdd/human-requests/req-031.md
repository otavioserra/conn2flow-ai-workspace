## 🎯 1. Diagnóstico & Justificativa Técnica

Atualmente, os desenvolvedores do ecossistema Conn2Flow contam com mais de 30 tarefas automatizadas configuradas no `.vscode/tasks.json` e uma ampla gama de comandos no CLI `c2f`. No entanto, a execução dessas tarefas exige o uso de atalhos de teclado (`Ctrl+Shift+P`), busca textual em listas longas ou digitação manual no terminal.

Ao criar a **Extensão Oficial do VS Code (`conn2flow-tools`)**, elevamos a experiência do desenvolvedor para o padrão das melhores ferramentas modernas de software:
- Um painel dedicado na barra lateral com o ícone do Conn2Flow;
- Categorização clara em acordeões navegáveis (SDD, Docker/Logs, Manager, Projetos e IA);
- Disparo 1-Click de tarefas diretamente no terminal integrado;
- Visibilidade em tempo real no rodapé do editor.

## 🛠️ 2. Especificação Técnica da Extensão

### A. Estrutura de Diretórios (`vscode-extension/`)
Criar na raiz de `conn2flow-ai-workspace`:
```
vscode-extension/
├── package.json
├── tsconfig.json
├── README.md
├── resources/
│   └── icon.png (ou conn2flow-logo.svg)
└── src/
    ├── extension.ts
    ├── providers/
    │   └── conn2flowTreeProvider.ts
    └── commands/
        ├── sddCommands.ts
        ├── dockerCommands.ts
        ├── managerCommands.ts
        └── projectCommands.ts
```

### B. Árvore de Navegação e Acordeões da Barra Lateral
A extensão deve registrar uma View Container com ID `conn2flow-view-container` e uma View `conn2flow-explorer` contendo:

1. **🏛️ SDD & Governança Viva**:
   - `conn2flow.sdd.openCurrent`: Abre o arquivo `sdd/human-requests/CURRENT.md`.
   - `conn2flow.sdd.openSpec`: Abre o arquivo `sdd/SPEC.md`.
   - `conn2flow.sdd.openChecklist`: Abre `sdd/validation/VALIDATION-CHECKLIST.md`.
2. **🐳 Docker & Logs em Tempo Real**:
   - `conn2flow.docker.status`: Executa `docker ps` no terminal integrado.
   - `conn2flow.docker.logsApache`: Executa `docker logs conn2flow-app --tail 50 --follow`.
   - `conn2flow.docker.logsPhp`: Executa `docker exec conn2flow-app bash -c "tail -f /var/log/php_errors.log"`.
   - `conn2flow.docker.truncatePhpLog`: Executa limpeza do arquivo de log PHP.
3. **🛠️ Manager & Core (Sistema)**:
   - `conn2flow.manager.updateAll`: Dispara a tarefa de atualização completa do sistema.
   - `conn2flow.manager.syncResources`: Executa `c2f resources:sync` (ou script PHP de recursos).
   - `conn2flow.manager.cssRebuild`: Executa `c2f css:rebuild`.
   - `conn2flow.manager.cssAudit`: Executa `c2f css:audit`.
4. **🗃️ Projetos**:
   - `conn2flow.projects.updateAll`: Dispara a tarefa de atualização de projeto selecionado.
   - `conn2flow.projects.deploy`: Dispara o deploy de projeto.
5. **📚 AI Workspace Hub**:
   - `conn2flow.ai.syncSkills`: Executa `./scripts/sync-all-repos.ps1`.
   - `conn2flow.ai.validateSkills`: Executa `php cli/c2f.php ai:sync`.
   - `conn2flow.ai.openPlaybook`: Abre o `docs/pt-br/PLAYBOOK-ORQUESTRACAO-MULTI-AGENTES.md`.
   - `conn2flow.ai.openCatalog`: Abre o `docs/pt-br/CATALOGO-DE-SKILLS.md`.

### C. Status Bar Item
Criar dois itens na barra de status inferior:
1. `$(server) Docker: Online/Offline` (clicável para ver status).
2. `$(git-commit) SDD: Ativo` (clicável para abrir `CURRENT.md`).

### D. Empacotamento `.vsix`
Configurar scripts no `package.json`:
- `compile`: Compila o TypeScript;
- `watch`: Compilação contínua;
- `package`: Gera o arquivo `.vsix` usando `@vscode/vsce`.
