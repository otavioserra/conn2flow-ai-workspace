## 🎯 1. Diagnóstico & Justificativa Técnica

Com base na documentação oficial da Anthropic para o Claude Code Desktop (`https://code.claude.com/docs/en/desktop`), identificamos oportunidades para elevar a robustez e a autonomia da nossa infraestrutura:

### 1.1. Isolamento de Worktrees sem Perda de Configurações (`.worktreeinclude`)
* **Problema**: O Claude Desktop (e comandos com `--worktree`) gera diretórios isolados em `.claude/worktrees/`. Arquivos gitignorados como `.env` e `environment.json` não eram replicados, resultando em falhas de conexão com o banco Docker ou exigindo cópias manuais propensas a erro.
* **Solução Canônica**: Adicionar o arquivo `.worktreeinclude` na raiz do projeto. O Claude Desktop lê esse arquivo e copia automaticamente os arquivos gitignorados especificados para qualquer novo worktree gerado:
  ```text
  .env
  .env.local
  dev-environment/data/environment.json
  temp/agent-cookies.txt
  ```

### 1.2. Autoverificação Visual Nativa no Browser Pane (`.claude/launch.json`)
* **Problema**: A verificação visual pós-edição dependia de scripts customizados ou execução headless de validação.
* **Solução Canônica**: O Claude Desktop possui um Browser Pane integrado que se conecta a dev servers locais. Com o arquivo `.claude/launch.json` configurado para `url: "http://localhost"` e `"autoVerify": true`, o próprio Claude Desktop inspeciona o DOM, tira screenshots e valida visualmente a renderização após cada edição de código.
  ```json
  {
    "version": "0.0.1",
    "autoVerify": true,
    "configurations": [
      {
        "name": "conn2flow-local",
        "url": "http://localhost"
      }
    ]
  }
  ```

### 1.3. Side Chats (`/btw` ou `Ctrl+;`) e Transição de Terminal (`/desktop`)
* O comando `/btw` abre um **Side Chat** que herda todo o contexto da sessão ativa, mas não grava suas mensagens na thread principal, ideal para tirar dúvidas técnicas sem poluir o histórico de requisitos do SDD.
* O comando `/desktop` no terminal CLI migra instantaneamente uma sessão de terminal ativa para o Claude Desktop.

## 🛠️ 2. Especificação Técnica das Alterações

### A. Criação de `.worktreeinclude`
1. Criar na raiz de `conn2flow-ai-workspace` com o conteúdo:
   ```text
   .env
   .env.local
   dev-environment/data/environment.json
   temp/agent-cookies.txt
   ```
2. Adicionar `.worktreeinclude` nas 4 pastas de template do Claude Kit:
   - `templates/pt-br/templates/spec-driven-project-claude-kit/.worktreeinclude`
   - `templates/pt-br/templates/private-project-claude-kit/.worktreeinclude`
   - `templates/en/templates/spec-driven-project-claude-kit/.worktreeinclude`
   - `templates/en/templates/private-project-claude-kit/.worktreeinclude`

### B. Criação de `.claude/launch.json`
1. Criar em `.claude/launch.json` em `conn2flow-ai-workspace` com o conteúdo:
   ```json
   {
     "version": "0.0.1",
     "autoVerify": true,
     "configurations": [
       {
         "name": "conn2flow-local",
         "url": "http://localhost"
       }
     ]
   }
   ```
2. Adicionar `.claude/launch.json` nas 4 pastas de template do Claude Kit:
   - `templates/pt-br/templates/spec-driven-project-claude-kit/.claude/launch.json`
   - `templates/pt-br/templates/private-project-claude-kit/.claude/launch.json`
   - `templates/en/templates/spec-driven-project-claude-kit/.claude/launch.json`
   - `templates/en/templates/private-project-claude-kit/.claude/launch.json`

### C. Atualização dos Scripts de Instalação do Claude Kit
Atualizar `scripts/install-spec-driven-claude-kit.ps1` e `scripts/install-spec-driven-claude-kit.sh` para:
- Copiar `.worktreeinclude` para a raiz do repositório destino;
- Copiar `.claude/launch.json` para a pasta `.claude/` do repositório destino.

### D. Atualização dos Playbooks de Orquestração Multi-Agentes
Atualizar `docs/pt-br/PLAYBOOK-ORQUESTRACAO-MULTI-AGENTES.md` e `docs/en/MULTI-AGENT-ORCHESTRATION-PLAYBOOK.md` adicionando a seção sobre o **Claude Code Desktop (Code Tab)**:
- Uso do `.worktreeinclude` para sessões paralelas com `.env`;
- Uso do `.claude/launch.json` com `autoVerify` no Browser Pane;
- Comando `/desktop` para transicionar do terminal para a GUI;
- Comando `/btw` (ou `Ctrl+;`) para Side Chats sem poluir o histórico do SDD.
