# REQ-001: Reorganização Bilingue & Melhoria de Instaladores

## 1. Problema
O repositório `conn2flow-ai-workspace` possui apenas templates em Português e não traz um boilerplate da pasta `sdd/` pronto para uso em novos repositórios. Além disso, os instaladores orientados a especificação (SDD) não suportam rebatismo de agentes ou seleção de idioma de origem.

---

## 2. Ajuste Requerido

### A. Reorganização Física das Pastas do Workspace
Mover e traduzir os templates para a seguinte estrutura bilingue:
- Mover a pasta `templates/` legada para `pt-br/templates/`.
- Criar a pasta `en/templates/` contendo as versões em Inglês de todos os quatro kits (traduzindo os prompts, `CLAUDE.md`, arquivos de regras `.claude/rules/*.md`, configurações de agentes `.claude/agents/*.md` ou `.github/agents/*.agent.md`, etc.).

### B. Criação dos Boilerplates SDD
Criar as estruturas base do SDD:
- Em `pt-br/sdd-boilerplate/sdd/`: Boilerplate limpo em Português.
- Em `en/sdd-boilerplate/sdd/`: Boilerplate limpo em Inglês.
- Cada boilerplate deve conter: `README.md`, `00-baseline-architecture.md`, `SPEC.md`, `process/00-START-HERE.md`, `process/01-WORKFLOW.md`, `human-requests/README.md`, `human-requests/CURRENT.md`, `human-requests/req-000.md`, `decisions/DECISION-LOG.md`, `implementation/BATCH-INDEX.md` e `validation/VALIDATION-CHECKLIST.md`.

### C. Atualização dos Scripts Instaladores
Atualizar os quatro scripts em `scripts/`:
- Inserir o parâmetro opcional `-Language` (PowerShell, default `"pt-br"`) ou `--language` (Bash, default `"pt-br"`), que aceita `"en"` ou `"pt-br"`.
- Alterar o caminho de leitura do template para apontar dinamicamente para `..\$Language\templates\<kit-name>`.
- Adicionar detecção: Se a pasta `sdd/` não existir na pasta alvo, copiar a pasta `sdd` contida em `..\$Language\sdd-boilerplate\sdd` para a raiz do destino. Se já existir, preservar os arquivos existentes do usuário (copiando apenas hooks).
- Adicionar suporte a `-AgentPrefix` (ou `--agent-prefix`) nos scripts spec-driven (Claude e Copilot) para renomear os agentes leves e atualizar recursivamente os apontamentos nos arquivos de prompts, regras e configurações do kit copiado.

### D. Criação dos Utilitários de Sincronização Reversa
Criar na pasta `scripts/`:
- `sync-back-template.ps1`
- `sync-back-template.sh`
Eles devem permitir trazer atualizações operacionais de prompts e regras feitas em repositórios de clientes de volta para a pasta de templates correspondente no workspace.

---

## 3. Arquivos Impactados
- Todos os instaladores em `scripts/`
- Criação de novos diretórios `en/` e `pt-br/`
- Novas estruturas de boilerplate

---

## 4. Plano de Validação
- Executar os instaladores localmente direcionando para uma pasta temporária `temp/test-repo-sdd`.
- Validar se o idioma é selecionado corretamente com `-Language en` ou `-Language pt-br`.
- Validar se a pasta `sdd/` é criada quando ausente no destino.
- Validar se o prefixo de agente é aplicado corretamente nos arquivos gerados.
