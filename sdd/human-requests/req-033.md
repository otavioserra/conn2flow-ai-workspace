## 🎯 Objetivo da Requisição

Implementar na extensão oficial do VS Code (`conn2flow-tools`) o **Assistente de Clonagem 1-Click de Repositórios Oficiais** e o **Scaffold Automático de Novos Projetos Satélites**, integrando o ciclo de vida completo de desenvolvimento com `environment.json` e a Tríade de Agentes.

---

## 📋 Critérios de Aceite

1. **Assistente de Clonagem 1-Click**:
   - `ProjectsManager`: Implementar `cloneMissingRepository(repoName: string)` que executa `git clone https://github.com/otavioserra/<repoName>.git` no diretório pai (`../`).
   - Comando `conn2flow.projects.cloneRepository`: Lista os repositórios faltantes e permite clonar com 1 clique.
   - Atualizar `checkRepositories` para oferecer a opção de clonagem imediata caso algum repositório não seja encontrado.

2. **Scaffold Automático de Novos Projetos Satélites**:
   - Comando `conn2flow.projects.scaffoldProject`:
     * Wizard interativo no VS Code para capturar: ID do projeto, Nome, URL e modo local/remoto;
     * Criação física da pasta do projeto (`../<id>/`);
     * Provisionamento da estrutura canônica do Gestor:
       - `<id>/gestor/`
       - `<id>/gestor/modulos/`
       - `<id>/gestor/assets/`
       - `<id>/gestor/resources/`
       - `<id>/README.md`
     * Cópia dos kits de IA normativos (`.claude/` e `.gemini/`) para o novo projeto;
     * Cadastro automático do projeto em `devProjects` no `dev-environment/data/environment.json`, aderente ao template canônico do Core.

3. **Compilação, Empacotamento e Instalação**:
   - Compilação TypeScript com 0 erros (`npm run compile`).
   - Empacotamento VSIX compliant (`vsce package`).
   - Reinstalação forçada no VS Code local (`code --install-extension --force`).

4. **Governança SDD & Paridade**:
