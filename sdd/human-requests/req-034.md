## 🎯 Objetivo da Requisição

Criar o **Sistema de Ponte da Tríade (Disparo 1-Click do Executor, Handoff de Terminal e Sincronização Automatizada)** na extensão do VS Code e no SDD, permitindo que o humano dispare o Claude Code com 1 clique, copie prompts prontos com regras normativas, registre logs de terminal em `sdd/handoffs/` e notifique o Arquiteto para auditoria contínua sem esforço manual.

---

## 📋 Critérios de Aceite

1. **Estrutura de Handoffs no SDD**:
   - Criar diretório `sdd/handoffs/` para troca de bastão entre Arquiteto e Executor.
   - Criar template canônico `sdd/handoffs/CURRENT-HANDOFF.md` com status de execução, notas do terminal e evidências.

2. **Ponte de Agentes na Extensão do VS Code (`conn2flowTreeProvider.ts` / `agentBridgeManager.ts`)**:
   - Criar seção na árvore: **`🤝 Ponte da Tríade (Disparo & Handoff)`**.
   - Comando `conn2flow.bridge.launchClaudeGoal`:
     * Abre terminal dedicado e envia o comando do Claude Code no modo `/goal` apontando diretamente para o briefing em `sdd/human-requests/CURRENT.md`.
   - Comando `conn2flow.bridge.copyExecutorPrompt`:
     * Lê a requisição ativa em `CURRENT.md`, empacota o prompt completo com regras de ouro e copia para a área de transferência do sistema via `vscode.env.clipboard.writeText`.
   - Comando `conn2flow.bridge.recordTerminalHandoff`:
     * Abre `sdd/handoffs/CURRENT-HANDOFF.md` no editor para colar notas rápidas ou log do terminal.
   - Comando `conn2flow.bridge.notifyArchitect`:
     * Faz commit e push das evidências do lote no Git para notificação da esteira.

3. **Compilação, Empacotamento e Instalação**:
   - Compilar TypeScript (`npm run compile`).
   - Empacotar `.vsix` limpo (`vsce package`).
   - Reinstalar com `code --install-extension --force`.

4. **Governança SDD & Paridade**:
   - Atualizar `sdd/human-requests/CURRENT.md` apontando para `req-034.md`.
   - Criar `sdd/implementation/batch-036.md`.
   - Validar com `php cli/c2f.php ai:sync`.
   - Commitar via `git add <caminhos-especificos>`.
