## 🎯 Diagnóstico dos Problemas

1. **Falha no Build Docker do MCP Hub**:
   - `apk add --no-cache bash php82 php82-json ...` falha no Alpine porque a distro utiliza o pacote padrão `php` (e no PHP 8+ o módulo `json` é embutido no core e não existe como pacote separado).
   - **Correção**: Ajustar `mcp-hub/Dockerfile` linha 14 para:
     `RUN apk add --no-cache bash php php-phar php-mbstring php-openssl php-curl git`
2. **Setup Automatizado de MCP (1-Click Connector Installer)**:
   - Criar `scripts/setup-mcp-connectors.ps1` e `scripts/setup-mcp-connectors.sh` para autodetectar Claude Desktop (`claude_desktop_config.json`), Cursor (`.cursor/mcp.json`) e VS Code (`.vscode/settings.json`) e injetar o bloco `"conn2flow-hub"` de forma não destrutiva.
3. **Comando no Core CLI**:
   - Criar `AiMcpSetupCommand.php` em `conn2flow/cli/src/Commands/Ai/` para o comando `c2f ai:mcp-setup`.
