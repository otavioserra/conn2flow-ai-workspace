## 1. Justificativa e Diagnóstico Técnico

Esta requisição consolida as pendências operacionais pós-homologação do lote BATCH-055 e a manutenção preventiva de governança do ecossistema Conn2Flow:

1. **Poda e Memory Gardening no Ecossistema SDD**:
   - A governança do framework estipula que nenhum arquivo de memória ativa de agentes (`sdd/MEMORIA-*.md`) deve exceder **50 KB**. Acima disso, a janela de contexto dos modelos sofre saturação prematura e perda de raciocínio.
   - A auditoria identificou que `lumix/sdd/MEMORIA-ENGENHARIA-EXECUCAO.md` atingiu **52.36 KB** devido ao acúmulo de notas transitórias e fatias antigas já homologadas.
   - Procedimento oficial de poda (`sdd-memory-gardening`):
     * Promover padrões universais para as skills (`.claude/skills/`, `.gemini/skills/`) e `sdd/SPEC.md`.
     * Compactar histórico de lotes concluídos em resumos de 2 a 3 linhas (*Causa raiz ➔ Solução adotada ➔ Guarda criada*).
     * Mover históricos extensos de depuração para `sdd/archive/`.
     * Substituir advertências temporárias pelo marco de versão do Core que as resolveu.
     * Reduzir o arquivo para a faixa alvo de **20 KB a 30 KB** (estritamente abaixo de 35 KB).
   - Higienizar `MEMORIA-ENGENHARIA-CHEFIA.md` nos repositórios, limpando pendências já resolvidas.

2. **Publicação, Empacotamento e Validação Operacional de Release**:
   - **Release do Core/Gestor**: Validar a execução do workflow de release (`release-gestor.yml`) no GitHub Actions, assegurando que a suíte de testes PHPUnit roda 100% verde no runner Ubuntu (com as correções de compatibilidade Windows/Linux da REQ-053).
   - **Empacotamento da Extensão VS Code**: Gerar o pacote VSIX oficial da extensão (`conn2flow-tools-1.1.1.vsix`) atualizado com o novo comando de build (`npm run package` / `vsce package`).
   - **Validação Operacional dos Recursos**:
     * Leitura de logs da VM com `sudo tail -n 100` sem erro de `Permission denied`.
     * Rebuild remoto de CSS com modo duplo (CLI nativo + fallback PHP) em `lab.conn2flow.local`.
     * Barra de status dinâmica `$(vm) Conn2Flow VM` e busca documental.

3. **Mapeamento e Levantamento do Backlog Restante**:
   - Elaborar relatório consolidado dos itens remanescentes no backlog para direcionar o próximo ciclo de intake humano.
