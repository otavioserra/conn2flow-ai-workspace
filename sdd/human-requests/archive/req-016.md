```markdown
## 🛡️ Espectro de 3 Níveis de Autonomia de IA

1. **Nível 1: SUPERVISIONADO (Padrão Mandatório / Human-in-the-Loop)**
   - O agente codifica e testa, mas **NÃO realiza commit ou deploy automático**.
   - O desenvolvedor revisa os diffs no chat do VS Code antes de consolidar.

2. **Nível 2: AUTÔNOMO MONITORADO (Live Autopilot / Glass-Box no Chat)**
   - Ativado quando a requisição contiver `modo: autonomo_monitorado` ou o usuário autorizar acompanhar na tela.
   - O agente executa a esteira completa com **Live Todo List (`[ ]` ➔ `[x]`) visível em tempo real**:
     * Cria branch/worktree (`feat/req-XXX`).
     * Codifica e compila (`c2f resources:sync`).
     * Roda testes (`c2f db:test`).
     * **Executa deploy EXCLUSIVAMENTE em ambiente de teste local** (`c2f manager:update-all` ou Docker local).
     * ⛔ **PROIBIÇÃO ABSOLUTA: NUNCA REALIZAR DEPLOY AUTOMÁTICO EM PRODUÇÃO.**
     * Realiza commit e push na branch da fatia.
     * Entrega relatório executivo na tela.

3. **Nível 3: AUTÔNOMO HEADLESS (Background Silencioso / Black-Box)**
   - Ativado quando a requisição contiver `modo: autonomo_headless`.
   - O agente executa toda a esteira em segundo plano isolado via MCP Hub / Git Worktree, emitindo notificação com relatório apenas ao finalizar.
```
