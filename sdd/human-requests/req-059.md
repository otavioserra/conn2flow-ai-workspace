## 2. Cristalização dos Aprendizados em Skills Canônicas

A análise minuciosa das memórias de engenharia (`MEMORIA-ENGENHARIA-EXECUCAO.md` e decisões) dos 5 repositórios revelou técnicas fundamentais e armadilhas reais que devem ser transferidas para **skills canônicas permanentes**:

1. **`c2f-database-operations`**:
   - **Concorrência e Patch Atômico em JSON (`JSON_MERGE_PATCH`)**: Proibição de reescrever campos JSON inteiros (como `fields_values`) em contextos concorrentes (ex: webhooks de gateway vs submissão de usuário). Uso mandatório de `JSON_MERGE_PATCH` no MariaDB 11.8+ / MySQL 8+.
   - **Armadilha do `null` no `JSON_MERGE_PATCH` (RFC 7396)**: No MariaDB/MySQL, valor `null` remove a chave do objeto. Validação mandatória com `JSON_VALID` para evitar corrupção em `NULL`.
2. **`c2f-hooks-system`**:
   - **Sincronização de Hooks no Deploy SSH**: O pipeline de sincronização de projeto via SSH (`deploy_mode: ssh`) não sincroniza a tabela `hooks` automaticamente. Novos hooks declarados em `<modulo>.json` necessitam da execução de `atualizacoes_hooks_sincronizar()`.
3. **`c2f-gestor-functions`**:
   - **Contrato de `nome_especifico`**: Exigência de `nome_especifico` no array de interface quando a tabela não possui a coluna `nome` (evitando desvios silenciosos).
   - **`gestor_redirecionar()` com Caminhos Relativos**: Imposição de caminhos relativos (a função já prefixa o `url-raiz` e idioma).
   - **Roteamento AJAX Público em `without_permission`**: Uso mandatório de `<modulo>.ajax.public.php` para tráfego anônimo seguro sem disparar `interface_ajax_iniciar`.
4. **`c2f-modelo-templates`**:
   - **Mockup Defensivo de Widgets**: Padrão `<!-- widgets#SIG < --> mockup <!-- widgets#SIG > -->` para evitar telas em branco e manter classes Tailwind no build quando o widget devolver vazio.
   - **Isolamento de Fragmentos de Formulário**: Envolver blocos-fragmento (opções, password toggles) em `<template>` para não vazarem código no DOM vivo.
5. **`c2f-shell-and-windows-traps`**:
   - **Armadilha 10**: Heredoc no Git Bash colapsa `\` em `\`; usar `DIRECTORY_SEPARATOR` ou substituição segura em scripts/PHP.
   - **Armadilha 11**: Proibição de `grep -rn` na raiz de repositórios no Windows por estouro de timeout.
