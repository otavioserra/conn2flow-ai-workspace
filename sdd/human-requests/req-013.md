## 🧭 Matriz Completa de Comandos a Implementar (`conn2flow/cli/src/Commands/`)

### 1. 🛠️ Recursos & Banco (`resources:*` & `db:*`)
* `c2f resources:sync` ➔ Executa compilação de recursos (`atualizacao-dados-recursos.php`).
* `c2f db:update [--project=ID]` ➔ Executa `updates-manager-database.sh`.
* `c2f db:test` ➔ Executa testes de banco com PHPUnit.

### 2. 🧠 IA & SDD (`ai:*`)
* `c2f ai:sync` ➔ Sincroniza e valida as 32 skills em todos os kits.
* `c2f ai:prune-memories` ➔ Executa Memory Gardening nas memórias de execução.

### 3. 📦 Módulos & Gestor (`module:*` & `manager:*`)
* `c2f module:create <id>` ➔ Scaffold canônico baseado em `modulos-grupos`.
* `c2f manager:build` ➔ Executa `build-local-manager.sh`.
* `c2f manager:sync-files` ➔ Executa `synchronize-manager.sh checksum`.
* `c2f manager:update-all` ➔ Executa sequência completa de update (Resources + Files + DB).
* `c2f manager:commit <msg>` ➔ Executa `commits/commit.sh`.
* `c2f manager:release <type> <tagMsg> <commitMsg> [mode]` ➔ Executa `releases/release.sh`.

### 4. 🧩 Plugins Privados e Públicos (`plugin:*`)
* `c2f plugin:sync [private|public]` ➔ Sincroniza plugin ativo (`synchronizes.sh checksum`).
* `c2f plugin:build [private|public]` ➔ Build local de plugin (`build-local-manager-plugin.sh`).
* `c2f plugin:resources [private|public]` ➔ Compilação de recursos de plugin (`update-data-resources-plugin.php`).
* `c2f plugin:commit <msg> [private|public]` ➔ Commit de plugin.
* `c2f plugin:release <type> <tagMsg> <commitMsg> [private|public]` ➔ Release de plugin.

### 5. 🗃️ Projetos (`project:*`)
* `c2f project:sync-core <projectID>` ➔ `sync-core-to-project.sh --project ID`.
* `c2f project:sync-resources <projectID>` ➔ `update-resource-data.sh --project ID`.
* `c2f project:sync-files <projectID> [--contents=Sim|Não]` ➔ `synchronize-project.sh`.
* `c2f project:sync-db <projectID>` ➔ `updates-manager-database.sh --project ID`.
* `c2f project:update-all <projectID>` ➔ Sequência completa de sincronização do projeto.
* `c2f project:deploy <projectID> [--contents=Sim|Não]` ➔ `deploy-project-v2.sh`.
* `c2f project:recover <projectID> [--contents]` ➔ `recover-project.sh`.
* `c2f project:update-system [--project=ID]` ➔ `update-system.sh`.

### 6. 🔧 Instalador (`installer:*`)
* `c2f installer:sync` ➔ `synchronize-manager-installer.sh checksum`.
* `c2f installer:build` ➔ `build-local-manager-installer.sh`.
* `c2f installer:new` ➔ `create-new-installation.sh`.
* `c2f installer:release <type> <tagMsg> <commitMsg> [mode]` ➔ `release-installer.sh`.

### 7. 🐳 Docker & Frontend (`docker:*` & `tailwind:*`)
* `c2f docker:status` ➔ `docker ps`.
* `c2f docker:php-version` ➔ `docker exec conn2flow-app bash -c "php -v"`.
* `c2f docker:logs [--follow]` ➔ Logs do Apache e PHP.
* `c2f docker:truncate-logs` ➔ Limpa `/var/log/php_errors.log`.
* `c2f tailwind:fix-spacing [--target=path]` ➔ `fix-tailwind-spacing.js`.
