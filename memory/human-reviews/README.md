# Human Reviews

Esta pasta é a **Caixa de Entrada Oficial de Homologação (Inbox)** das IAs para o Humano-no-Loop.
Aqui a Tríade de Agentes deposita os relatórios formais de revisão (`rev-XXX.md`) após auditoria de lotes, aguardando validação e assinatura humana.

---

## 🛡️ Regras de Governança

1. **Padrão Nominal**: Fichas sequenciais nomeadas como `rev-001.md`, `rev-002.md`, etc.
2. **Regra dos 10 Ativos**: No máximo 10 revisões ativas na raiz desta pasta. Fichas homologadas mais antigas são migradas para `archive/`.
3. **Padrão Dual-Tier em `archive/`**:
   - `archive/compacted/`: Resumos consolidados de homologações históricas.
   - `archive/original/`: Fichas integrais preservadas para auditoria forense.
4. **Assinatura Obrigatória**: O lote só é considerado formalmente encerrado após a homologação humana (`[x] Homologado por: ...`).
