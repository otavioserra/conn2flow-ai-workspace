# Backlog de Ideias e Propostas Técnicas

Este diretório armazena propostas, pesquisas, épicos e itens de arquitetura que estão em incubação.

## Estados do Backlog:
* **`ICEBOX`**: Ideias guardadas para avaliação futura sem urgência imediata.
* **`IN-DISCUSSION`**: Itens em debate técnico ou refinamento arquitetural.
* **`READY`**: Itens refinados e prontos para promoção.

> [!IMPORTANT]
> **Intake Gate**: Nenhum item deste diretório é diretamente executável por agentes de IA até promoção humana explícita para `sdd/human-requests/req-XXX.md`, atualização de `CURRENT.md` e associação a um batch.
