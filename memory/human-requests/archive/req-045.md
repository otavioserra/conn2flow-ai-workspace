## Objetivo

1. Corrigir o erro de preflight na preparação de release do gestor instalador (`O preflight de release falhou: gestor-instalador\index.php`) na extensão VS Code (`releaseManager.ts`) e no script de versionamento do Core (`version-installer.php`), adequando a leitura e o incremento de versão à constante `InstallerGuard::VERSION` em `gestor-instalador/src/InstallerGuard.php`.
2. Formalizar a **Diretriz de Sonda HTTP (Rewrite Probe)** na governança e nas skills (`c2f-html-css-pages-and-components` / `c2f-dev-scripts`), estabelecendo que testes de loopback HTTP devem partir do front-end/navegador para prevenir deadlock de workers no PHP-FPM em ambientes single-pool.
3. Propagar o contrato canônico do console CLI (`Conn2Flow\Cli\Contracts\CommandInterface` e `BaseProcessCommand`) em todas as documentações e skills (`c2f-dev-scripts`), evitando alucinações de comandos baseados em Symfony direto.

---

## Escopo Detalhado

### 1. Correção do Preflight de Release do Instalador na Extensão (`releaseManager.ts`)
- **Causa Raiz**: O preflight falhava ao tentar extrair uma string literal direta no `index.php`. Com a introdução do `InstallerGuard` no instalador v2, a versão canônica reside em `const VERSION = '2.1.0';` em `gestor-instalador/src/InstallerGuard.php`, enquanto `index.php` referencia `InstallerGuard::VERSION`.
- **Ação**:
  * Em `vscode-extension/src/providers/releaseManager.ts`:
    * Atualizar a definição do produto `installer` para verificar e ler a versão em `gestor-instalador/src/InstallerGuard.php` (com fallback retrocompatível para `gestor-instalador/index.php`).
    * Usar regex resiliente: `/(?:const\s+VERSION|\$_GESTOR_INSTALADOR\[['"]versao['"]\])\s*=\s*['"]?(\d+\.\d+\.\d+)['"]?/` ou ler `InstallerGuard.php` diretamente (`const VERSION = '...'`).

### 2. Atualização do Script de Versionamento do Instalador no Core (`version-installer.php`)
- Em `ai-workspace/en/scripts/releases/version-installer.php` (e `pt-br` se houver):
  * Atualizar o script de incremento de versão para localizar e atualizar `const VERSION = '...'` em `gestor-instalador/src/InstallerGuard.php`, atualizando também o comentário descritivo em `gestor-instalador/index.php`.

### 3. Governança de Sondas HTTP (Anti-Deadlock PHP-FPM)
- Formalizar na skill `c2f-html-css-pages-and-components/SKILL.md` e `c2f-dev-scripts/SKILL.md`:
  * **Regra Anti-Deadlock**: Toda sonda de conectividade / URL rewrite HTTP (como `api/rewrite-probe` ou `__c2f_rewrite_check__`) deve ser disparada de forma assíncrona pelo **cliente front-end (navegador/JavaScript)** e nunca por cURL loopback síncrono interno dentro do próprio processo PHP no servidor, prevenindo exaustão e travamento do PHP-FPM em ambientes locais ou single-worker.

### 4. Governança do Core CLI (`CommandInterface`)
- Sincronizar em `c2f-dev-scripts/SKILL.md` e documentações de desenvolvimento a regra canônica de que novos comandos implementam `Conn2Flow\Cli\Contracts\CommandInterface` ou estendem `Conn2Flow\Cli\Commands\BaseProcessCommand`.

### 5. Testes Automatizados
- Adicionar teste em `vscode-extension/test/` validando que o preflight e leitura de versão do gestor instalador (`readVersion` para `installer`) funcionam com sucesso contra o formato de `InstallerGuard.php` e `index.php`.
- Rodar `npm test` garantindo 100% dos testes verdes.
