## 🎯 Objetivo Operacional

Integrar o servidor oficial **Chrome DevTools MCP (`chrome-devtools-mcp`)** à infraestrutura de IA e agentes do Conn2Flow (`conn2flow-ai-workspace` e repositórios satélites), permitindo que agentes inspecionem ativamente e em tempo real a execução do runtime PHP/JS (DOM, erros de console com stack traces, requisições AJAX assíncronas, status HTTP e capturas de tela/layout).

---

## 📋 Escopo de Implementação

### 1. Configuração do Servidor MCP (`.gemini/mcp_config.json`)
* Adicionar a definição canônica do servidor `chrome-devtools` no `.gemini/mcp_config.json` da matriz `conn2flow-ai-workspace` e nos templates dos kits:
  ```json
  "chrome-devtools": {
    "command": "npx",
    "args": [
      "-y",
      "chrome-devtools-mcp@latest",
      "--allow-unrestricted-paths"
    ]
  }
  ```

### 2. Script Auxiliar de Inicialização e Sandbox (`scripts/mcp/`)
* Criar script de suporte `scripts/mcp/launch-devtools-chrome.ps1` que garanta:
  * Criação e isolamento de perfil temporário (`--user-data-dir` isolado em diretório sandbox/temp).
  * Inicialização do Chrome com porta de depuração remota ativada (ex: `--remote-debugging-port=9222`).
  * Opções para modo headless (`--headless=new`) ou modo interativo com janela.
  * Proteção contra acesso a credenciais pessoais ou histórico do usuário.

### 3. Revisão Ampla e Atualização das Skills Oficiais
O agente executor **DEVE realizar uma varredura crítica em todo o catálogo das 41 skills canônicas** para mapear e atualizar quais skills se beneficiam das novas capacidades de depuração e inspeção do Chrome DevTools MCP:
* **Skills Primárias Obrigatórias**:
  * **`c2f-agent-visual-inspection`**: Adicionar instruções para inspeção ativa com `navigate_page`, `take_screenshot`, `take_snapshot`, medição de nós do DOM e checagem visual de layouts em tempo real.
  * **`c2f-javascript-ajax`**: Adicionar instruções para depuração de chamadas assíncronas (`/_ajax/`, `/_api/`) utilizando `list_console_messages` (com stack traces), `list_network_requests` e `get_network_request` (incluindo validação de headers e CSRF).
* **Skills Candidatas para Mapeamento e Enriquecimento**:
  * **`c2f-tailwind-css-architecture`**: Detecção de estilos inativos (*inactive CSS styles*), conflitos de especificidade e validação visual de classes Tailwind compiladas.
  * **`c2f-interface-v2-architecture`**: Validação de componentes dinâmicos em tela (Fomantic UI, Semantic UI, dropdowns, abas e responsividade em múltiplos dispositivos).
  * **`c2f-quill-editor`**: Verificação do rendering real do editor no DOM, montagem da toolbar e binding com inputs ocultos.
  * **`c2f-preview-modals-system`**: Validação de abertura de modais, overlays e dimensionamento dinâmico.
  * **`c2f-reviewer-agent`**: Inclusão de critérios de homologação em runtime nos relatórios de auditoria (`review-XXX.md`).
  * **`c2f-shell-and-windows-traps`**: Armadilhas de processos zumbis do Chrome no Windows, portas de depuração ocupadas (`9222`) e caminhos de sandbox temporário.
* O agente executor deve registrar formalmente em `sdd/implementation/batch-065.md` todas as skills analisadas e o racional das alterações realizadas.

### 4. Propagação Global e Auditoria MD5
* Propagar todas as skills atualizadas e a configuração de MCP para os **25 kits** dos **5 repositórios** (`conn2flow-ai-workspace`, `conn2flow`, `conn2flow-site`, `lumix`, `transformamp`).
* Executar auditoria de paridade MD5 garantindo 100% de consistência e preservando skills locais de satélites.
* Rodar a suíte de testes `npm test` garantindo conformidade.
