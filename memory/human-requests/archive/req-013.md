## 🎯 Diagnóstico dos Problemas

1. **Falha no Build Docker do MCP Hub**:
   - `apk add --no-cache bash php82 php82-json ...` falha no Alpine do `node:20-alpine` porque a distro utiliza o pacote padrão `php` (e no PHP 8+ o módulo `json` é embutido no core e não existe como pacote separado).
   - **Correção**: Ajustar para `RUN apk add --no-cache bash php php-phar php-mbstring php-openssl php-curl git`.
2. **Cross-Terminal Hardening**:
   - Garantir que `./c2f` funcione nativamente no Git Bash/Linux/macOS e `c2f.bat`/`c2f.cmd`/`c2f.ps1` no CMD e PowerShell com auto-fallback.
3. **Catálogo Exaustivo de Comandos (Cobertura 100% do `tasks.json`)**:
   - Implementar todos os comandos de instaladores, plugins públicos/privados, sincronização de projetos, builds e releases em `conn2flow/cli/src/Commands/`.
4. **Visibilidade Operacional & Live Todo List**:
   - O agente deve renderizar no início e atualizar continuamente uma **Todo List em Markdown (`[ ]` / `[x]`)** a cada etapa concluída.
5. **Setup Automatizado de MCP (1-Click Connector Installer)**:

* `c2f manager:release <type> <tagMsg> <commitMsg> [mode]` ➔ `releases/release.sh`.

### D. 🧩 Plugins Privados e Públicos (`plugin:*`)
* `c2f plugin:sync [private|public]` ➔ Sincroniza plugin ativo (`synchronizes.sh checksum`).

### E. 🗃️ Projetos (`project:*`)

### F. 🔧 Instalador (`installer:*`)
