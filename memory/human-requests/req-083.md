## 🎯 Diretriz do Engenheiro Chefe Humano

As árvores de trabalho principais dos repositórios satélites pertencem aos chefes/frentes ativas de cada projeto e **não devem ter trabalho alheio alterado, commitado ou descartado**.

Para publicar as skills homologadas (`c2f-architect-master`, `c2f-executor-agent`, `c2f-multilingual-skills-governance`, `c2f-mdd-indexing-and-handoffs`, mais o manifesto `conn2flow/memory/sync-customizations.json` no Core) de forma limpa na `main` de cada satélite, o Executor deve operar em **worktree temporária isolada**, fazer **commit seletivo + merge na `main` + `git push origin main`**, e ao final **remover e deletar completamente cada worktree temporária** (`git worktree remove` + `git worktree prune`).

---

## 📋 Escopo e Procedimento Seguro por Satélite (`BATCH-085`)

Para cada um dos 9 repositórios satélites listados em `completions/BATCH-084-executor-receipt.json`:

1. **Auditoria inicial sem destrutividade**:
   - Registrar raiz original, branch atual (`git branch --show-current`), status atual (`git status --short`) e remoto (`git remote -v`).
   - **Nunca** executar `git reset --hard`, `git checkout -- .`, `git clean` ou `git add -A` na árvore principal do satélite.
2. **Criação da worktree temporária isolada (REGISTRO OBRIGATÓRIO — `REQ-077`)**:
   - Atualizar referências remotas (`git fetch origin`).
   - Criar worktree temporária em pasta irmã/temporária dedicada (ex.: `../_wt-req083-<repo>`), partindo de `origin/main` numa branch temporária (ex.: `chore/sync-skills-req-083`), e registrar raiz original + caminho temporário no `batch-085.md`.
   - Aplicar **somente** as 4 skills homologadas da matriz (`c2f-architect-master`, `c2f-executor-agent`, `c2f-multilingual-skills-governance`, `c2f-mdd-indexing-and-handoffs`) nos kits existentes dentro da worktree (no Core `conn2flow`, preservar a variante reconhecida de `c2f-multilingual-skills-governance` com título “⚡ Gatilho Obrigatório” e atualizar `memory/sync-customizations.json`).
   - Conferir `git diff` dentro da worktree para garantir que **apenas** os arquivos de skills homologadas (e manifesto do Core) foram tocados.
3. **Commit seletivo, Merge na `main` e `git push`**:
   - Na worktree, executar `git add <caminhos-especificos>` (proibido `git add -A` / `git add .`) e `git commit -m "chore(skills): sync canonical skills from conn2flow-ai-workspace (REQ-081/REQ-082)"`.
   - **Integração segura na `main` e push**:
     - Se a árvore principal do satélite **não** estiver com `main` checked out (ex.: `conn2flow-site` em `feat/req-292-docs-mdd`): atualizar/mesclar `main` via fast-forward/merge limpo a partir da branch da worktree e executar `git push origin main` (sem mexer na branch de feature ativa na árvore principal).
     - Se a árvore principal **estiver** com `main` checked out:
       * Se a árvore principal estiver limpa (ou contendo apenas as próprias cópias idênticas das 4 skills já aplicadas na `REQ-082`, sem conflito com trabalho alheio), integrar a branch da worktree na `main` com segurança (ou fazer `git push origin chore/sync-skills-req-083:main` e alinhar `git fetch origin` sem tocar no trabalho não relacionado) — **sem nunca sobrescrever ou destruir alterações alheias**.
       * Se houver conflito real ou bloqueio de segurança na `main` (ex.: divergência remota ou arquivo modificado fora do escopo em conflito), **não forçar** (`--force` é proibido); preservar o trabalho, registrar o bloqueio exato no `batch-085.md` e reportar ao Macro-Arquiteto.
4. **Remoção e limpeza obrigatória das worktrees (`REQ-077`)**:
   - Após confirmar o push e a integridade da `main` remota (`origin/main`), auditar que não resta trabalho não integrado na worktree.
   - Remover cada worktree com `git worktree remove <caminho>` (sem `--force` destrutivo sobre trabalho não integrado), deletar a branch temporária `chore/sync-skills-req-083` já mesclada (`git branch -d`) e executar `git worktree prune`.
   - Confirmar com `git worktree list` em cada satélite que nenhuma worktree temporária da `REQ-083` restou no disco.
5. **Relatório final do lote (`memory/implementation/batch-085.md`)**:
   - Tabela consolidada dos 9 satélites contendo: repositório, raiz original, caminho temporário da worktree, status do commit/merge/push (`origin/main` SHA), confirmação de remoção da worktree (`git worktree list` limpo) e eventuais impedimentos preservados.
   - Incluir o **Relatório de Dificuldades e Aprendizados para o AI Workspace** (`FEAT-017`) e atualizar `memory/validation/VALIDATION-CHECKLIST.md` + índices MDD.
