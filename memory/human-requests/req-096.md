## 📋 Escopo do Lote (`BATCH-098`)

### 1. Pull Remoto com Cache Global no `mdd-client` (`mdd sync --remote`)
- Evoluir `mdd sync` (e criar alias curto opcional **`mdd update`**) em `tools/mdd-client/src/mdd_client/sync.py` (e `cli.py`):
  1. **Flags novas**:
     - `--remote` (habilita sincronização sem precisar de `--matrix` local no disco);
     - `--source-url <url>` (padrão: `https://github.com/otavioserra/conn2flow-ai-workspace.git`);
     - `--cache-dir <dir>` (padrão: `~/.mdd/cache/conn2flow-ai-workspace`);
     - `--domain <auto|id>` (respeita o domínio do projeto detectado/configurado — ex.: `generic` atualiza apenas o núcleo MDD + personas; `conn2flow` atualiza o catálogo do domínio);
     - `--check-only` (consulta se há atualizações disponíveis sem gravar nada, retornando JSON estruturado com lista de skills desatualizadas e choques).
  2. **Cache leve e seguro**:
     - Se o cache ainda não existe: `git clone --depth 1 <source-url> <cache-dir>`.
     - Se já existe: `git -C <cache-dir> fetch --depth 1 origin main` + `git -C <cache-dir> reset --hard origin/main` (apenas no cache descartável dentro de `~/.mdd/cache/`, **nunca** em repositórios do usuário!).
     - Runner de Git injetável para testes unitários 100% offline no `pytest`.
  3. **Preservação absoluta (`DEC-136`)**:
     - Atualiza **somente** skills oficiais do domínio que mudaram na matriz e que **não** tenham conflito local não reconhecido.
     - **Nunca** sobrescreve nem apaga **skills locais do projeto** (ex.: `<projeto>-project-guide`) nem customizações reconhecidas em `memory/sync-customizations.json`.
     - Conflitos locais são reportados como choques pendentes (`conflicts`) para decisão do usuário.
- Cobrir com testes unitários completos em `tools/mdd-client/tests/test_remote_sync.py` (mantendo cobertura global `>= 95%` no comando exato do CI!).

### 2. Auto-Sync Periódico na Extensão VS Code (`v1.2.4`)
- Adicionar configurações em `vscode-extension/package.json` (com traduções limpas PT-BR e EN em `package.nls*.json` e `localizationCatalog.ts`):
  - **`conn2flow.autoSyncSkills`**: `"off"` | `"notify"` | `"auto"` (padrão: **`"notify"`** — seguro por padrão!).
  - **`conn2flow.autoSyncIntervalHours`**: número (padrão: **`24`**).
  - **`conn2flow.remoteMatrixUrl`**: string (padrão: `"https://github.com/otavioserra/conn2flow-ai-workspace.git"`).
- **Comportamento ao ativar a extensão** (respeitando Workspace Trust e o intervalo configurado salvo em `globalState` / `workspaceState`):
  - Se `"off"`: não executa nada.
  - Se `"notify"`: roda `mdd sync --remote --check-only --json` em segundo plano; se houver atualizações sem conflito, exibe aviso discreto na barra de status (respeitando a política da extensão sem `showInformationMessage` intrusivo) + item/botão **"Atualizar Skills do GitHub"** na aba **MDD Hub & Skills Control**.
  - Se `"auto"`: roda `mdd sync --remote --apply --json` automaticamente para itens sem conflito e registra o resumo no Output Channel `Conn2Flow MDD Hub` (preservando choques para revisão).
- Expor comando manual **"Sincronizar Skills Remotas (GitHub)"** na aba **MDD Hub & Skills Control** e no Command Palette.
- Atualizar `vscode-extension/README.md` (documentando o Auto-Sync!), `CHANGELOG.md`, bump para **`1.2.4`**, validar testes (`100% PASS`) e empacotar **`vscode-extension/conn2flow-tools-1.2.4.vsix`**.
