# SDD Memory Gardening

1. Measure execution-memory bytes and lines, then read the complete file.
2. Keep only the 3 to 5 most recent tasks and still-active follow-ups.
3. Distill stable recurring rules into `SKILL.md` files at the Core or project-specific layer.
4. Never change Chief Memory without an explicit human instruction.
5. Rewrite Execution Memory toward 5 KB and below 10 KB.
6. Check skill frontmatter, discovery paths, and a recoverable Git diff.
7. Record final sizes and evidence in the batch checklist.
