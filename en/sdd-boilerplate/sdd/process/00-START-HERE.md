# 00 Start Here

Use this file as the entry point for any new request.

## Step 1: resolve the intake

1. Read `sdd/human-requests/CURRENT.md`.
2. If the request comes from `sdd/human-requests/`, treat that material as non-normative intake.

## Step 2: minimum reading order

1. `sdd/README.md`
2. `sdd/00-baseline-architecture.md`
3. `sdd/SPEC.md`
4. `sdd/implementation/BATCH-INDEX.md`
5. `sdd/validation/VALIDATION-CHECKLIST.md`
6. `sdd/decisions/DECISION-LOG.md`

## Step 3: classify early

- normative change
- incremental implementation
- review
- validation

## Step 4: protect the baseline

Before changing structural behavior, confirm the delta against the approved baseline.
